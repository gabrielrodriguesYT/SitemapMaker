Como Gerar seu Sitemap XML

Aprenda o processo completo para criar um sitemap XML eficiente para seu site

1

Preparar seu Site

Antes de gerar o sitemap, certifique-se de que seu site está pronto:

  • Todas as páginas importantes estão publicadas e acessíveis
  • Não há links quebrados ou páginas com erro 404
  • O site possui uma estrutura de navegação clara
  • As URLs são amigáveis e seguem uma lógica consistente

Esta preparação garante que o sitemap gerado seja completo e preciso.

2

Acessar o SiteMapMaker

Vá até a página de geração de sitemap do SiteMapMaker:

Gerar Sitemap - SiteMapMaker

Não é necessário criar conta ou fazer login. O serviço é 100% gratuito.

3

Inserir a URL do Site

No campo indicado, digite a URL completa do seu site, incluindo "http://" ou "https://".

Exemplo: https://www.meusite.com

Certifique-se de usar a URL canônica (principal) do seu site.

4

Configurar as Opções

Personalize as opções de acordo com suas necessidades:

  • Incluir imagens: Recomendado para sites com conteúdo visual
  • Incluir vídeos: Importante para sites com conteúdo em vídeo
  • Limitar a 500 páginas: A maioria dos sites se beneficia desta limitação
  • Frequência de alteração: Defina conforme a atualização do seu conteúdo
  • Prioridade: Atribua prioridades diferentes para tipos de páginas
5

Gerar e Baixar o Sitemap

Clique no botão "Gerar Sitemap" e aguarde o processamento.

Uma vez concluído, você pode:

  • Visualizar o XML gerado
  • Copiar o código para usar posteriormente
  • Fazer o download do arquivo sitemap.xml

Salve o arquivo em um local seguro do seu computador.

Implementando o Sitemap no seu Site

Aprenda a colocar o sitemap no seu site para que os mecanismos de busca possam encontrá-lo

1

Fazer Upload do Arquivo

Transfira o arquivo sitemap.xml para o diretório raiz do seu site:

  • Acesse seu painel de hospedagem ou use FTP
  • Navegue até a pasta principal (normalmente "public_html" ou "www")
  • Faça upload do arquivo sitemap.xml

O arquivo deve estar acessível através de: https://seusite.com/sitemap.xml

2

Adicionar ao robots.txt (Opcional)

Para facilitar que os crawlers encontrem seu sitemap, adicione esta linha ao arquivo robots.txt:

Sitemap: https://seusite.com/sitemap.xml

Coloque esta linha preferencialmente no início ou no final do arquivo robots.txt.

3

Verificar se está Acessível

Abra seu navegador e digite a URL completa do sitemap para verificar se está funcionando:

https://seusite.com/sitemap.xml

Se aparecer o conteúdo XML, significa que o sitemap está corretamente instalado.

Enviando para o Google Search Console

O passo mais importante para garantir que o Google conheça e indexe todas as páginas do seu site

1

Acessar o Google Search Console

Vá até Google Search Console e faça login com sua conta Google.

Se você ainda não adicionou seu site, clique em "Adicionar propriedade" e siga as instruções para verificar sua propriedade.

2

Navegar até a Seção Sitemaps

No menu lateral, clique em "Sitemaps" na seção "Indexação".

Esta é a área onde você pode enviar e gerenciar seus sitemaps.

3

Adicionar Novo Sitemap

No campo "Adicionar um novo sitemap", digite o caminho para seu sitemap:

sitemap.xml

Clique em "Enviar" para registrar seu sitemap no Google.

4

Monitorar o Status

Após o envio, o Google começará a processar seu sitemap. Você pode verificar:

  • Status: Mostra se o sitemap foi processado com sucesso
  • Última leitura: Quando o Google acessou seu sitemap pela última vez
  • URLs descobertas: Quantas URLs foram encontradas no sitemap

O processamento pode levar de alguns dias a algumas semanas.

Otimizando seu Sitemap

Dicas para extrair o máximo benefício do seu sitemap XML

✓

Atualize Regularmente

Gere um novo sitemap sempre que adicionar conteúdo significativo ao seu site ou alterar sua estrutura.

⚡

Use Prioridades Inteligentes

Atribua prioridades mais altas para páginas importantes como homepage, páginas de produto e conteúdo principal.

🔄

Ajuste Frequências

Defina frequências de atualização realistas. Blog posts podem ser "diariamente", enquanto páginas institucionais "mensalmente".

📅

Mantenha Lastmod Atualizado

Atualize a data da última modificação (lastmod) sempre que fizer alterações significativas em uma página.

🚫

Exclua Conteúdo Não Indexável

Não inclua no sitemap páginas com noindex, páginas de login, ou conteúdo duplicado.

📊

Monitore no Search Console

Verifique regularmente o Google Search Console para ver como suas páginas estão sendo indexadas.

Dicas Avançadas e Melhores Práticas

Vá além do básico com estas estratégias avançadas de sitemap

Sitemaps para Imagens e Vídeos

Para sites ricos em mídia, considere criar sitemaps específicos:

  • Sitemap de imagens: Inclui todas as imagens importantes do site
  • Sitemap de vídeos: Especialmente útil para conteúdo em vídeo
  • Sitemap de notícias: Para sites de notícias que usam o Google News

O SiteMapMaker permite incluir imagens e vídeos no sitemap principal.

Sitemap Index para Sites Grandes

Para sites com milhares de páginas, crie um sitemap index que referencia múltiplos sitemaps:

<?xml version="1.0" encoding="UTF-8"?> <sitemapindex xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"> <sitemap> <loc>https://www.example.com/sitemap-pages.xml</loc> <lastmod>2023-10-15</lastmod> </sitemap> <sitemap> <loc>https://www.example.com/sitemap-images.xml</loc> <lastmod>2023-10-15</lastmod> </sitemap> </sitemapindex>

Compatibilidade com Outros Mecanismos de Busca

Além do Google, outros mecanismos de busca também usam sitemaps:

  • Bing Webmaster Tools: Oferece funcionalidades similares ao Google Search Console
  • Yandex Webmaster: Para tráfego russo e de países vizinhos
  • Baidu Webmaster Tools: Para o mercado chinês

Envie seu sitemap para essas plataformas se seu público-alvo inclui essas regiões.

Perguntas Frequentes sobre Sitemaps

Respostas para as dúvidas mais comuns sobre sitemaps XML

Com que frequência devo atualizar meu sitemap?

Recomendamos atualizar seu sitemap sempre que:

  • Adicionar novas páginas significativas ao site
  • Remover páginas existentes
  • Mudar a estrutura de URLs do site
  • Fazer alterações importantes no conteúdo das páginas

Para a maioria dos sites, uma atualização mensal é suficiente. Para sites com conteúdo muito dinâmico, considere atualizações semanais.

Meu sitemap tem um limite de tamanho?

Sim, o Google recomenda os seguintes limites:

  • Arquivo sitemap individual: Máximo de 50MB (não compactado) ou 50.000 URLs
  • Sitemap index: Pode referenciar até 50.000 sitemaps individuais

Se seu site exceder esses limites, divida-o em múltiplos sitemaps e use um sitemap index.

Preciso de sitemap se meu site é pequeno?

Mesmo para sites pequenos, um sitemap é benéfico porque:

  • Ajuda o Google a descobrir todo o conteúdo, mesmo com poucos backlinks
  • Fornece informações sobre a importância relativa das páginas
  • Indica com que frequência o conteúdo é atualizado
  • Pode acelerar a indexação de novo conteúdo

Para sites com menos de 10 páginas, o benefício é menor, mas ainda recomendado.

O sitemap garante que minhas páginas serão indexadas?

Não, o sitemap é apenas uma recomendação para os mecanismos de busca. O Google pode optar por não indexar algumas páginas devido a:

  • Conteúdo de baixa qualidade ou duplicado
  • Problemas de rastreabilidade
  • Diretivas no robots.txt ou meta tags
  • Penalidades manuais ou algoritmicas

O sitemap aumenta as chances, mas não garante a indexação.

Posso usar o mesmo sitemap para diferentes subdomínios?

Não, cada subdomínio é tratado como um site separado pelos mecanismos de busca. Você precisa:

  • Criar um sitemap separado para cada subdomínio
  • Verificar cada subdomínio individualmente no Google Search Console
  • Enviar o sitemap específico para cada propriedade

Exceção: se você usar domínios internacionais (como exemplo.com.br, exemplo.es), pode usar o mesmo sitemap se configurar corretamente as tags hreflang.
